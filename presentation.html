معماری و کلیت پروژه CryptoPay

این پروژه یک پلتفرم پرداخت رمزنگاری شده با دو پنل مختلف طراحی‌شده برای کاربران عادی و فروشندگان است. برنامه با Laravel 12 و Blade ساخته شده و از راهکارهای سرور-ساید رندر استفاده می‌کند. در لایه فرانت‌اند از Tailwind CSS، Alpine.js، Axios و Vite بهره گرفته شده است.

Laravel 12 Blade Templates Tailwind CSS Alpine.js Axios Vite SQLite / MySQL

پنل کاربر (User)

قسمت کاربر برای مدیریت کیف پول‌های دیجیتال، ارسال و دریافت ارز، مشاهده تراکنش‌ها و پرداخت فاکتورها طراحی شده است.

  • داشبورد دارایی با محاسبه موجودی دلاری بر اساس قیمت‌های لحظه‌ای
  • لیست کیف پول‌ها با ارزهای BTC، ETH و USDT
  • انتقال رتبه‌ای داخلی بین آدرس‌های کیف پول با بررسی تطابق ارز
  • مشاهده تاریخچه تراکنش‌ها با فیلتر نوع، ارز و جستجو
  • پرداخت فاکتورهای فروشنده و بازگشت خطا برای موجودی ناکافی
  • تنظیمات پروفایل و گزینه‌های نمایش مانند دارک مود و اعلان‌ها

پنل فروشنده / مارکت (Merchant)

پنل فروشنده برای ایجاد درخواست پرداخت، پیگیری فاکتورها، تسویه‌ها و تحلیل آماری درآمد ساخته شده است.

  • داشبورد فروشنده با میزان درآمد، پرداخت‌های در انتظار و پرداخت‌های تکمیل‌شده
  • ایجاد درخواست پرداخت با شماره فاکتور و آدرس گیرنده
  • مدیریت کیف پول‌های فروشنده و ساخت آدرس‌های جدید
  • مشاهده تراکنش‌ها و دریافت‌های مرتبط با والت‌های فروشنده
  • صفحه تسویه‌حساب و فاکتورهای pending/pay
  • تنظیمات کسب‌وکار شامل نام فروشگاه، ایمیل، آدرس، مجوز و وب‌سایت
مدل‌های اصلی Users, Wallets, Transactions, PaymentRequests, Notifications
تخصیص نقش‌ها admin, merchant, user به کمک RoleMiddleware و فیلد role در جدول users
امنیت و گیت‌ها middleware auth, verified, role; بررسی مالکیت در کنترلرها; CSRF در فرم‌ها
سرویس ویژه CryptoPrice برای دریافت قیمت Binance با کش و استفاده از fallback
این پروژه سرور-ساید است و به صورت SPA با React ساخته نشده است. از Blade و قالب‌های Laravel برای رندر صفحات استفاده می‌کند.
