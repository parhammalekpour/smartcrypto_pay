ساختار فنی پروژه SmartCrypto Pay

دیتابیس و مدل‌ها
  • مدل‌ها: User, Merchant, Wallet, Transaction, Notification و ...
  • ارتباط بین مدل‌ها: هر کاربر یک یا چند کیف پول، هر تراکنش وابسته به کاربر و پذیرنده
  • دیتابیس: معمولاً MySQL/PostgreSQL
کنترلرها و ویوها
  • کنترلرها: مدیریت درخواست‌های کاربر و پذیرنده، تراکنش‌ها، احراز هویت
  • ویوها: صفحات SPA با استفاده از React.js یا Blade (در صورت استفاده از Laravel)
امنیت و اسکافولد
  • استفاده از JWT یا Passport برای احراز هویت
  • میدل‌ورهای امنیتی: Auth, Throttle, CORS, Role-based Access
  • گیت‌ها: Policy/Permission برای کنترل دسترسی
امکانات و کتابخانه‌های خاص
  • SPA (Single Page Application) با React.js یا Vue.js
  • استفاده از کتابخانه‌های امنیتی مانند bcrypt و helmet
  • امکان توسعه API برای اتصال به سایر سرویس‌ها
